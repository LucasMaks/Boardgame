
Description
-An application developed in C# using WPF (Windows Presentation Foundation) is used to manage a collection of board games. 
It allows games to be saved in JSON format and also offers a game draw function, which can be particularly useful when organising 
tournaments or selecting a game for a certain number of players.

Features
-Saving of games:

--Ability to add new games to the collection.

--Each game is saved in JSON format for easy storage and processing.

-Drawing for Games:

--Drawing for Tournaments: A function that draws games that can be used in tournaments.

--Filtering by Number of Players: Ability to search for games that are suitable for a certain number of players (e.g. games for 5 people).

-Browsing Collections:

--The user can browse their entire collection of games.

--Ability to edit existing entries or remove games from the list.

-Graphical User Interface (WPF):

--Intuitive user interface with the ability to add, edit and delete games.

--Buttons to draw games and filter by number of players.
